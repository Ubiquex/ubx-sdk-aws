# ubx-sdk-aws

Typed bindings for AWS (`[dynamic_providers.aws]`, CloudFormation-registry
sourced via `ubx-provider-dynamic`), generated by
[ubx](https://github.com/ubiquex/ubiquex) (`ubx sdk gen`), for all three
SDK languages in one combined repo:

- [`sdk/go/`](sdk/go/) — Go bindings, module `github.com/ubiquex/ubx-sdk-aws/sdk/go/v2`
  (a subdirectory Go module at major version 2, tagged `sdk/go/v2.Y.Z` — Go's own
  semantic import versioning requires the `/v2` path suffix once a module crosses v2)
- [`sdk/typescript/`](sdk/typescript/) — TypeScript bindings, published to npm as
  [`@ubx/sdk-aws`](https://npmjs.com/package/@ubx/sdk-aws)
- [`sdk/python/`](sdk/python/) — Python bindings, published to PyPI as
  [`ubx-sdk-aws`](https://pypi.org/project/ubx-sdk-aws/)

One package per AWS service boundary (`ecr/`, `iam/`, `sqs/`, ...), one
file per resource type, in every language.

## Install

```
go get github.com/ubiquex/ubx-sdk-aws/sdk/go/v2
npm install @ubx/sdk-aws
pip install ubx-sdk-aws
```

## v2.0.0: real service identity, not a mechanical name split

`1.0.0`'s own package boundaries were derived by splitting each
resource's flat wire type name on `_` and guessing the service from the
second token alone. That guess was wrong for AWS's historical EC2/VPC
bare-name resources (`aws_instance` landed in `instance/`, not `ec2/`)
and for every multi-word real AWS service (`aws_api_gateway_deployment`
landed in `api/`, not `apigateway/`). `2.0.0` uses CloudFormation's own
real namespace field directly instead of guessing.

**919 of 1,710 real resource types (53.7%) move to a different package
in this release.** Full list, with the two real root causes explained:
[`docs/v2.0.0-namespace-changes.md`](docs/v2.0.0-namespace-changes.md).
Breaking for any import of an affected type in any of the three
languages — there is no compatibility shim; the old package for a moved
type no longer exists.

Also picks up AWS's own registry drift since `1.0.0`'s last fetch
(`VERSION`'s own `spec-sha256` changed independently of this codegen
fix — CloudFormation added/changed real resource types between
2026-08-23 and 2026-08-25).

Go's module path gains the `/v2` suffix
(`github.com/ubiquex/ubx-sdk-aws/sdk/go/v2`) per Go's own semantic
import versioning rules for any module at major version 2 or above —
tagged `sdk/go/v2.0.0`, replacing the old path's own `sdk/go/v1.0.0`
tag convention.

## v1.0.0: source change, not just a version bump

Every version before `1.0.0` was generated from the `hashicorp/aws`
Terraform provider. As of `1.0.0`, this repo is generated from AWS's
own real CloudFormation resource-type registry
(`schema.cloudformation.<region>.amazonaws.com`, `[dynamic_providers.aws]`
in `ubiquex`), the source `ubx` actually resolves and applies changes
against today. The old `hashicorp/aws`-shaped identifiers are gone —
they described a schema `ubx` no longer uses, not a subset of the
current one. Real, checked overlap between the two schemas is small and
what does name-match often disagrees field-for-field (CFN-only fields
absent from the old publish, Terraform-only synthetic fields like
`tags_all` absent from CFN) — this is a genuine source change, not a
compatible superset.

CloudFormation's own registry publishes no discrete, pinnable release
either (a live registry zip, not a tagged version) — `VERSION` records
what was actually fetched: a SHA-256 of the raw schema zip, the fetch
date, and the source URL, the same content-hash convention
`ubx-sdk-datadog`/`ubx-sdk-github` use for the same reason.

This repo-shaped-per-provider layout (UBI-138) supersedes the earlier
one-repo-per-(provider,language) convention (UBI-98/UBI-103) — matches
the real Pulumi precedent this project cites (`pulumi/pulumi-aws`'s own
`sdk/go/`, `sdk/python/`, `sdk/nodejs/`). Package names on every
registry are unchanged; only Go's module path changed, because a
subdirectory Go module requires it.

Every file except each language's own `doc.{go,ts}` / `__init__.py` is
generated — do not hand-edit; re-run `ubx sdk gen` after the source
schema changes.

Depends on the shared runtime: [ubx-sdk-go](https://github.com/ubiquex/ubx-sdk-go) (Go),
[`jsr:@ubx/sdk`](https://jsr.io/@ubx/sdk) (TypeScript),
[`ubx-sdk`](https://pypi.org/project/ubx-sdk/) (Python, imported as `ubx_sdk`).
